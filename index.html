Timeline POC
Editor Player

Private timelines, portable forever.

A local-first scrapbook prototype for creating simple life, travel, project, or career timelines. This proof of concept keeps editing data in IndexedDB and exports plain JSON that the standalone player can open.

Launch editor Open player

Local-first

Timeline drafts are saved in the browser through IndexedDB. No account, backend, or cloud upload is involved in this prototype.

Structured data

Events use a small shared JSON format, so the editor and player can evolve independently around the same document contract.

Exportable

Save an editable JSON backup or a standalone HTML file with the selected player embedded.
