Timeline JSON format

A timeline is saved as a single UTF-8 JSON file, named *.timeline.json. This page describes the current schema, version 10. The editor and players read every older version, and anything they don't recognise is preserved rather than discarded.

Overview

{
  "format": "local-timeline-poc",
  "version": 10,
  "title": "Europe",
  "updatedAt": "2026-09-19T20:45:35.484Z",
  "eventTypes": [ ... ],
  "hiddenEventTypes": [ ... ],   // optional
  "collections": [ ... ],
  "media": [ ... ],
  "events": [ ... ]
}
KeyTypeDescription
formatstringAlways "local-timeline-poc". Files with any other value are rejected.
versionintegerSchema version, currently 10. Older files are migrated on load; newer files load with a warning.
titlestringThe timeline's name.
updatedAtstringISO 8601 date-time of the last save.
eventTypesarrayThe categories events can belong to. See Event types.
hiddenEventTypesarray of stringsOptional. Built-in types the author has removed from their list.
collectionsarrayNamed groups of events, such as a trip. See Collections.
mediaarrayEmbedded images. See Media.
eventsarrayThe events themselves, sorted by date and time. See Events.

Events

{
  "id": "40f5dc82-0fc8-4e3c-b6d5-0aa287c6b569",
  "type": "travel",
  "title": "Frankfurt",
  "timestamp": { "date": "2026-09-01", "time": "09:30", "tz": "Europe/Berlin" },
  "endTimestamp": { "date": "2026-09-03", "time": "00:00", "tz": "Europe/Berlin" },
  "location": "Frankfurt",
  "geo": { "lat": 50.11064, "lng": 8.68209, "source": "search" },
  "images": [ ... ],
  "fields": [ ... ],
  "collectionIds": [ "681226a6-3692-496f-8318-bd806ea845ed" ]
}
KeyTypeDescription
idstringUnique within the file. Usually a UUID. A missing or duplicate id is replaced on load.
typestringThe value of one of the timeline's event types. Unknown types become "misc".
titlestringEvent name. Defaults to "Untitled event".
timestampobjectWhen the event starts. See Timestamps.
endTimestampobjectOptional. When the event ends, in the same shape. Ignored if it is earlier than the start.
locationstringFree-text place name. May be empty.
geoobjectOptional coordinates. See Coordinates.
imagesarrayThe event's photo gallery. See Image gallery.
fieldsarrayExtra labelled values. See Custom fields.
collectionIdsarray of stringsThe ids of the collections this event belongs to.

Timestamps

KeyTypeDescription
datestringYYYY-MM-DD.
timestring24-hour HH:MM. "00:00" is treated as "no time set" when displayed.
tzstringAn IANA time zone name, such as America/Vancouver. An end timestamp with no tz uses the start's.

Dates and times are wall-clock values in the given zone, not UTC offsets. Values that don't match the expected pattern are kept as written, with a warning on load.

Coordinates

KeyTypeDescription
latnumberLatitude, −90 to 90. Rounded to 5 decimal places.
lngnumberLongitude, −180 to 180. Rounded to 5 decimal places.
sourcestringOptional. Where the point came from: "search" (looked up from the location text), "map" (picked on the map) or "manual" (typed). A missing value means "manual". Only "search" coordinates are replaced by a later lookup without asking.

A geo that isn't a valid latitude/longitude pair is dropped.

Image gallery

Each item in an event's images array is one of two kinds.

{ "id": "…", "kind": "embedded", "mediaId": "…", "caption": "Old town" }
{ "id": "…", "kind": "link", "url": "https://example.com/photo.jpg", "caption": "" }
KeyTypeDescription
idstringUnique gallery item id.
kindstring"embedded" or "link".
mediaIdstringEmbedded only. The id of an entry in the top-level media array. Items pointing at a missing entry are dropped.
urlstringLink only. Must be http or https.
captionstringOptional caption; empty by default.

Custom fields

{ "id": "…", "key": "people", "label": "People", "type": "text", "value": "Sam, Alex" }
KeyTypeDescription
idstringUnique field id.
keystringMachine-friendly name. Built-in presets are summary, people, organization, role, project, url and notes; custom fields use a slug of their label.
labelstringDisplay label.
typestring"text" (the default) or "url".
valuestringAlways stored as text. Non-text values are converted to a string on load.

Event types

{ "value": "travel", "label": "Travel", "emoji": "✈️" }
KeyTypeDescription
valuestringA lowercase slug (a-z, 0-9, single hyphens) that events refer to.
labelstringDisplay name.
emojistringShort icon, up to 16 characters. Defaults to 🏷️.
custombooleanPresent and true on types the author added.

The built-in types are misc 📌, life ✨, family 👨‍👩‍👧‍👦, friends 🤝, health 🩺, home 🏠, school 🎓, travel ✈️ and work 💼. They are always available unless listed in hiddenEventTypes, and misc can't be hidden. A type still used by an event is never hidden.

Collections

{ "id": "681226a6-3692-496f-8318-bd806ea845ed", "kind": "collection", "title": "Germany trip" }
KeyTypeDescription
idstringUnique collection id, referenced from events' collectionIds.
kindstringCurrently always "collection".
titlestringDisplay name.

Collections that no event belongs to are left out when the file is saved.

Media

{
  "id": "…",
  "kind": "image",
  "mimeType": "image/jpeg",
  "dataUrl": "data:image/jpeg;base64,/9j/4AAQ…",
  "path": "",
  "width": 1600,
  "height": 1200,
  "originalName": "IMG_0042.jpg",
  "encodedAt": "2026-09-19T20:45:35.484Z"
}
KeyTypeDescription
idstringUnique media id, referenced by embedded gallery items.
kindstring"image".
mimeTypestring"image/jpeg". Only JPEG data URLs can be displayed.
dataUrlstringThe image itself as a data:image/jpeg;base64,… URL.
pathstringReserved for a file path; empty when the image is embedded.
width, heightnumberPixel dimensions.
originalNamestringThe source file's name, for reference.
encodedAtstringISO 8601 date-time the image was encoded.

Media that no gallery item references is left out when the file is saved.

Compatibility

  • Unknown keys are kept. Extra keys on the timeline, events, collections, event types, media, gallery items and fields survive a load and save, so you can add your own data.
  • Lenient reading. Missing or malformed values are repaired with sensible defaults (a new id, "misc" for an unknown type, today's date for a missing date) and reported as warnings instead of failing the load. Only a file that isn't a timeline object, or has a different format, is rejected.
  • Older versions load. Version 1 files (with name, date, time and tz directly on events) are migrated automatically, as are the type renames education → school, move → home and job → work.
  • Newer versions load too. A file with a higher version loads with a warning; the fields this app knows are read and the rest are preserved.

The reference implementation is src/timeline.js.
